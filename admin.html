Sign in with GitHub

This page has no password of its own. It only works with a GitHub access token that can write to the website's repository, so only the site's administrators can add or remove videos. Visitors can't upload anything.

How do I get an access token?
  1. Sign in to GitHub with the account that owns the website repository.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  3. Give it a name (e.g. "Video reviews") and an expiry date.
  4. Under Repository access, choose Only select repositories and pick the website repository only.
  5. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
  6. Generate the token, copy it, and paste it above. Never share it or put it in the website's code. If it leaks, delete it on GitHub and make a new one.
