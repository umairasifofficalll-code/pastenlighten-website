PAST ENLIGHTEN — GITHUB PAGES UPLOAD

1. Extract this ZIP on your computer.
2. Open your GitHub repository and select Add file > Upload files.
3. Upload the CONTENTS of this extracted folder (not the ZIP itself).
4. Keep the blog/ folder and all relative paths intact.
5. Commit changes.
6. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.

Important:
- The homepage is index.html.
- The blog listing is blog/index.html.
- Blog articles are separate HTML files inside blog/.
- Do not upload only index.html; upload all files and folders.
- All website photos are in the images/ folder (WebP, each in a large and a small "-sm" size).
  Upload the whole folder. The old assets/images/ folder is no longer used by any page.
- To swap a photo later, replace the file in images/ with one of the same name (both sizes).
- The tours/ pages linked from the homepage are still not included; add them from your original site.
